## Lo que he construido

- **API REST con Spring Boot**: servicios con Spring Data JPA, MySQL o PostgreSQL, validaciones y manejo global de excepciones.
- **Seguridad**: autenticación stateless con Spring Security y JWT, con roles CLIENTE y ADMIN.
- **Pruebas**: pruebas unitarias con JUnit 5 y Mockito, simulando dependencias para aislar la lógica de negocio.
- **Tiempo real**: mensajería con WebSocket (STOMP) y PostgreSQL, probada con varias sesiones simultáneas.
- **Buenas prácticas**: POO y clean code en proyectos de práctica como [java-crud](https://github.com/Keviin010/java-crud).
- **Visto en el Máster (en proceso de reforzar)**: microservicios con Spring Cloud (Eureka y balanceo de carga, ver [spring-cloud-microservices-ecosystem](https://github.com/Keviin010/spring-cloud-microservices-ecosystem)) y programación reactiva con Project Reactor / WebFlux.
